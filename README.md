# Data Science & Business Analytics Internship
## The Sparks Foundation (GRIP)

This repository contains the technical tasks completed during my Data Science internship at **The Sparks Foundation**. Each project focuses on implementing core machine learning concepts and data visualization techniques using Python.

---

## 📂 Project Overview

### 1. Supervised Machine Learning: Student Score Prediction
* **Objective:** Predict the percentage of a student based on the number of study hours.
* **Algorithm:** Simple Linear Regression.
* **Key Insight:** Established a clear correlation between study duration and academic performance.
* **Tools:** Scikit-learn, Pandas, Matplotlib.

### 2. Unsupervised Machine Learning: Iris Dataset Clustering
* **Objective:** Predict the optimum number of clusters and represent it visually.
* **Algorithm:** K-Means Clustering.
* **Methodology:** Used the **Elbow Method** to determine the value of $K$.
* **Tools:** Scikit-learn, Seaborn, NumPy.

### 3. Exploratory Data Analysis (EDA)
* **Objective:** Perform initial investigations on datasets to discover patterns, spot anomalies, and check assumptions using graphical representations.
* **Focus:** Data cleaning, feature engineering, and statistical summary.
